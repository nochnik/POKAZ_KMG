# KMG.AIAN — интро-показ

**Показ живёт здесь: https://nochnik.github.io/AIAN_DEMO/**

Интро-лента перед живой демонстрацией ИИ-ассистента KMG.AIAN и финальный
слайд эффектов. Открывается ссылкой в браузере — корень сайта сам
перенаправляет на `показ.html`.

## Карта обеспеченности — отдельная страница

**https://nochnik.github.io/AIAN_DEMO/карта.html**

Самостоятельный экран, ссылок на интро с него нет.

**Два такта до карты:** сначала логотип KMG.AIAN → нажатие → ассистент
думает (сколько нужно, анимация не кончается) → нажатие → думает ещё две
секунды, логотип уезжает влево, открывается карта. Управление — клик,
`→` или пробел (подсказки на экране нет). Пропустить заставку: `?сразу=1`.

- **Фильтры**: тип топлива (АИ-92 · АИ-95 · Дизтопливо · Авиатопливо),
  показатель (дни запаса · объём) и переключатель **учёта НП в пути** —
  он добавляет к запасу то, что уже едет в область, и пересобирает карту
  на новом числе;
- **Под каждой областью** написано, сколько ещё в пути — в тех же единицах,
  что выбраны: «+6 сут в пути» или «+2,7 тыс. т в пути»;
- **Цвет всегда считается по дням запаса**, даже когда на плашках тонны.
  Тонны между регионами несравнимы: Алматы держит больше, но и расходует
  больше. Дни = запас / среднесуточное потребление, поэтому 4 дня красные
  и в Ұлытау, и в Алматы. Пороги: 0–4 · 5–8 · 9–14 · дальше зелёный;
- наведение на область показывает запас, объём в пути, итог и суточный
  расход;
- ссылкой открывается нужное состояние:
  `?топливо=Дизтопливо&показатель=объём&путь=1`.

Данные — в [данные/запасы.json](данные/запасы.json), выгрузка ДАЦ. Запас —
на нефтебазах, «в пути» — **по данным КТЖ** (перевозка плюс импорт), дни —
целая часть от «запас / среднесуточное потребление», дополнительные сутки
считаются так же от объёма в пути, итог — сумма частей. По авиатопливу
суточное потребление не ведётся, поэтому дни для него не считаются и кнопка
«Дни запаса» гаснет. Пересчёт проверяется независимо скриптом сверки: 60
строк, расхождений нет.

## Управление

| Клавиша | Действие |
|---|---|
| `→` · пробел · клик | следующий такт |
| `←` | предыдущий такт |
| `End` | сразу финал (после живой демонстрации) |
| `Home` | вернуться на титул |
| `F11` | полный экран — так и показывать |

Курсор мыши прячется сам после 2,5 секунд неподвижности.

Такты идут по клику докладчика; внутри слайда и карты нажатия открывают
части такта по одной. Исключение — видеоцепочка: по её окончании лента
сама уходит в пролёт к карте. Шаг назад открывает предыдущий такт целиком.

## Служебные режимы (репетиции и проверка)

- `?такт=N` — открыть показ сразу с такта N (нумерация с 0);
- `&шаг=N` — открыть такт на нужном нажатии внутри него;
- `&снимок=1` — все анимации в конечном состоянии (покадровая проверка);
- `&пусто=1` — карта без линий и знака (служебный кадр).

Пример: `https://nochnik.github.io/AIAN_DEMO/показ.html?такт=3&шаг=2`

## Порядок тактов

0. Титул — KMG.AIAN
1. Слайд: 1 — данные разрознены (сложность расчёта потребления ГСМ) ·
   2 — оцифровать цепочку (от разрозненных данных — к единому интеллекту) ·
   3 — платформа (единый контур топливного баланса РК), затем три блока
   цепочки с источниками. **Шесть нажатий**, по одному на строку и блок.
   Подписи — по правке ДАЦ 08.09.
2. «Источники данных»: мозаика четырёх живых экранов ДАЦ — данные НПЗ,
   КТЖ, Министерства энергетики РК, КГД МФ РК (порядок и подписи — созвон с
   ДАЦ 09.09: только «Данные …» с полным именем источника, без пояснений).
   **Каждый экран — ссылка в живую систему на нужный отчёт** (адреса от
   ДАЦ): если на стенде попросят показать систему — клик по экрану открывает
   её новой вкладкой; стрелка вправо — просто следующий такт. Клик по экрану
   показ не листает. Стоит сразу после вводного слайда (ДАЦ 11.09). Клипы — в `медиа/данные/`, 960×540, зациклены.
3. Цепочка одним пролётом (видео, 20 с): орбита → скважина → магистральный
   трубопровод → НПЗ → налив в цистерны → отлёт → карта.
   Справа накапливаются карточки источников: Добыча → Транспортировка
   и переработка → Оборот НП. По окончании видео лента сама уходит дальше.
4. Карта: данные стекаются в ДАЦ → **нажатие**: AIAN думает и подсвечивает
   проблемный регион → **нажатие**: поставка с запада, регион зеленеет,
   слева выходит реплика AIAN.
5. Финал: четыре эффекта по одному снизу вверх — прозрачность рынка ·
   прогнозирование дефицита и профицита НП · топливно-энергетическая
   безопасность · снижение социального напряжения (текст ДАЦ), затем цифра
   «22,5 млрд тг» (снималась по установке председателя, Адильжан вернул
   08.09 — деньги остаются) и кнопка «Открыть живую систему» →
   https://aian.kmg.kz/.

## Показ без интернета

Папка репозитория — это весь показ. На месте достаточно:

```bash
python -m http.server 8091
```

и открыть `http://localhost:8091/`. Ничего не собирается, внешних
зависимостей нет: шрифты (`медиа/шрифты/`), анимационная библиотека
(`вендор/gsap.min.js`) и все данные лежат рядом.

## Из чего состоит

| Путь | Что это |
|---|---|
| `показ.html` | вся лента: такты, карта, анимации — один файл |
| `медиа/` | видеоряд (титульная петля, цепочка), рельеф карты, логотип, шрифты |
| `данные/области_кз.json` | точные контуры 20 регионов Казахстана |
| `данные/огни_кз.json` | огни городов для карты |
| `вендор/gsap.min.js` | анимации (самохостится — показ автономен) |
| `index.html`, `.nojekyll` | вход GitHub Pages |

Карта — гибрид: границы областей рисует вектор (точная география),
фактура под ними — генерированный рельеф, обрезанный контуром страны.
Весь текст — HTML-слой поверх, в видеокадры ничего не запекается.
