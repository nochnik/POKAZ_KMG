# Nedra.NUMEX Optimize — Оптимизация режимов разработки

Интерактивный цифровой модуль интерфейса ПО **Nedra.NUMEX Optimize v2.4** (модуль «Оптимизация режимов разработки»), созданный для демонстраций проектов блока разработки КМГ («Цифровое месторождение» / Центр цифрового развития).

---

## 📌 О модуле

Модуль представляет собой полноценную автономную интерактивную реплику интерфейса NUMEX Optimize взамен статичных видеороликов:
- **Аутентичный UI Windows / RDP**: заголовок окна с кнопками управления, панель удалённого сеанса RDP, брендовая шапка Nedra.NUMEX.
- **Вкладки приложения**: «Дашборд», «Планы разработки», «Финансовая модель», «Анализ чувствительности».
- **Интерактивный тулбар**: калиброванные иконки 32×32 SVG в квадратных кнопках 38×38 px, подсветка при наведении (`#fef984`), кнопка возврата масштаба (`Home`) с анимацией клика.
- **График оптимизации на SVG (Matplotlib-style)**:
  - **180 реальных расчетных точек** итерационного поиска оптимума из производственного процесса ПО.
  - **Базовый вариант** (оранжевый ромб `(-1.00, 186457.84)`).
  - **Начальная точка e0** (жёлтый ромб `(0.00, 177040.78)`).
  - **Оптимальный расчет e190** (зелёный ромб `(190.00, 217930.38)`).
  - **Расчетные итерации e2..e198** (синие маркеры).
  - Интерактивный тултип с контрастной жёлтой подложкой `#fef984`, рамкой и стрелкой-указателем при наведении на любую точку.
  - Адаптивный ресайз графика (`ResizeObserver`) под любые разрешения экрана.

---

## 🚀 Как запустить

Модуль полностью автономен и не требует сборки, Node.js, веб-серверов или внешних библиотек (Zero Dependencies, чистый HTML5/CSS3/SVG/ES6):

### 1. Автономный запуск (в браузере)
Просто откройте файл в любом браузере (Chrome, Edge, Safari, Firefox):
```bash
# Из корня репозитория:
open цд/numex_optimize/index.html
```

### 2. Импорт внутри 3D-презентации
Шаблон готов для встраивания в первый слайд `цд/первый_слайд_v3.html` (через `iframe` или импорт компонента).
