# Nedra.NUMEX Optimize — Оптимизация режимов разработки (v2.4)

Интерактивный цифровой модуль интерфейса ПО **Nedra.NUMEX Optimize v2.4** (модуль «Оптимизация режимов разработки»), созданный по видеозаписи реального процесса работы (`IMG_3903.MP4`) для демонстраций проектов блока разработки КМГ («Цифровое месторождение» / Центр цифрового развития).

---

## 📌 Возможности и экраны

Модуль представляет собой полноценную автономную интерактивную реплику интерфейса NUMEX Optimize (Zero Dependencies, чистый HTML5/CSS3/SVG/ES6):

1. **Аутентичный UI Windows и RDP-сеанса**:
   - Плавающий синий RDP-бар сеанса (`10.128.0.45 - Remote Desktop`) с кнопкой фиксации, индикатором связи и кнопками управления.
   - Фирменная шапка окна Windows с логотипом Недра и путём проекта: `Nedra.NUMEX Optimize - C:\Users\testus1\NUMEX\5 объект КМГИ\OptimA\EMG_V2`.
   - Синяя лента с горизонталями рельефа и выпадающими меню (`Файл`, `Проект`, `Стоимости`, `Экономика`, `Помощь`) с горячими клавишами.
   - Быстрый ряд иконок: открытие, сохранение, очистка, калькулятор, оптимизация.

2. **Вкладки приложения (1-в-1 по видео)**:
   - **«Дашборд»**: интерактивное подокно «Ход оптимизации» с SVG-графиком сходимости целевой функции на 180 реальных расчетных точек (Базовый вариант, e0, лучший расчет e190, итерации e2..e198), селекторами X/Y, кнопкой сброса масштаба (`Home`) и тултипом `#fef984` со стрелкой.
   - **«Результаты»**: таблица расчетов на 16 колонок (`Модель`, `Результат`, `Нефть т`, `Вода т`, `Жидкость т`, `Газ м³`, `Зак. воды м³`, `Зак. газа м³`, `Акт. наг.`, `Акт г/н`, `Акт. доб.`, `Новые скв.`, `Из б/д. в наг.`, `Из б/д. в доб.`, `Переводы`, `Диск. нефть`) с интерактивным выделением ячеек синей плашкой `#2563eb`.
   - **«Очередь расчетов»**: таблица расчетных заданий со статусами «завершен», временем начала, длительностью и узлом `MKHL9HX`.
   - **«Оптимизируемые скважины»**: таблица 22 скважин со статусами режимов (`доб. → доб.`, `наг. → наг.`, `б/д`), дебитами, забойными давлениями, коэффициентами эксплуатации, деревом раскрытия и правым тулбаром фильтрации.
   - **«Анализ чувствительности»**: торнадо-диаграмма влияния факторов на целевую функцию (NPV).

3. **Левый вертикальный тулбар**:
   - Калиброванная ширина `58px`, кнопки `38×38 px`, векторные SVG-иконки `32×32 px`, жёлтая подсветка при наведении (`#fef984` с рамкой `#877e26`), разделители `32px`.
   - Тултипы «Поскважинное отображение», «Среднедействующий фонд», «Ранжирование параметров и торнадо-анализ».

## 📂 Архитектура файлов

```text
цд/numex_optimize/
├── index.html              # Семантический каркас приложения
├── css/
│   ├── variables.css       # CSS-переменные (цвета, шрифты, отступы)
│   ├── layout.css          # Окно Windows, RDP-бар, шапка, меню, тулбар, табы
│   ├── dashboard.css       # Стили графика, тултипов и области анализа
│   └── views.css           # Стили экранов (таблицы скважин, очереди, результатов)
├── js/
│   ├── data/
│   │   ├── points-data.js  # Вынесенный массив 180 точек оптимизации
│   │   └── mock-data.js    # Данные скважин, очереди расчетов и результатов
│   ├── modules/
│   │   ├── chart.js        # Модуль SVG-графика с ResizeObserver
│   │   ├── tabs-router.js  # Роутер переключения экранов и вкладок
│   │   └── ui-controls.js  # Интерактивные меню, таблицы и тултипы
│   └── app.js              # Главная точка входа

```
