# Цифровой двойник наземной инфраструктуры и мониторинг добычи («Уаз»)

> **Интеллектуальная система оперативного контроля и технологического учета добычи нефти и газа месторождения «Уаз» (НГДУ «Доссормунайгаз» / АО «Эмбамунайгаз»).**

---

## 1. Для чего нужна система простыми словами

Система представляет собой **интерактивный цифровой двойник** наземного технологического комплекса месторождения. Она решает главную задачу диспетчера и технолога: **видеть весь путь нефти в реальном времени — от забоя скважины до сдачи в магистральный нефтепровод**.

Вместо десятков разрозненных таблиц и бумажных журналов на одном экране собраны:
1. **Текущий дебит скважин** (жидкость, нефть, процент обводненности).
2. **Замерные установки АГЗУ** (какая скважина сейчас на замере, давление, температура).
3. **Резервуарный парк (РГС и РВС)** (уровни взлива, разделение нефти и подтоварной воды).
4. **Печи подогрева** (температура сырья на входе и выходе перед перекачкой).
5. **Насосные станции и коммерческие узлы учета** (контроль перекачки на ЦППН «С.Жолдыбай» за 25 км).
6. **Выполнение плановых показателей** (годовой и суточный план, простои, ремонты ПРС/КРС).

Система работает автономно на видеостенах диспетчерских пунктов (разрешение 7680×2160), автоматически адаптируясь под экраны любых ноутбуков и мониторов без искажений и без лишней ширины, а также встроена в единый портал Ситуационного центра (`v4.html`).

---

## 2. Экран и адаптивное масштабирование

* **Родное разрешение:** Исходная схема спроектирована под промышленную видеостену из 4 объединенных 4K-панелей (суммарная сетка **7680 × 2160 px**).
* **Автоматическая подгонка по высоте (Auto-Zoom):** При открытии в браузере или во встроенном фрейме система мгновенно рассчитывает масштаб `scale = высота_окна / 2160`. Все шрифты, трубопроводы, резервуары и графики пропорционально масштабируются.
* **Устранение лишней ширины:** Ширина рабочей области страницы строго привязана к фактическому масштабу контента. Граница горизонтальной прокрутки заканчивается ровно там, где завершается технологическая схема (насосная и коллектор перекачки на Жолдыбай). Справа нет пустого черного пространства.

## 3. Интерактивная карта кликов: что умеет каждый элемент

### А. Верхняя панель ключевых показателей (KPI)

| Элемент | Значение по умолчанию | Что происходит при клике |
| :--- | :--- | :--- |
| **Фонд скважин** | `82` | Открывает модальное окно **«Сводная ведомость распределения фонда по категориям»**: распределение по способам эксплуатации (ЭЦН, ШГН, фонтан), действующий фонд, бездействие, нагнетательные и пьезометрические скважины. |
| **КЭС (%)** | `97.09%` | Открывает аналитику **коэффициента эксплуатации скважин**: баланс отработанного времени фонда, учет плановых и технологических простоев, межремонтный период (МРП). |
| **10 последних ГТМ/КРС** | Таблица работ | Открывает ведомость последних **геолого-технических мероприятий и капитальных ремонтов**: даты ввода, тип работ (РИР, дострел, СКО, перевод на другой горизонт) и фактический прирост добычи нефти (т/сут). |
| **10 последних ПРС** | Список ремонтов | Открывает журнал **текущего подземного ремонта скважин**: бригада ПРС, номер скважины, причина ремонта (смена глубинного насоса, обрыв штанг, промывка забоя) и продолжительность в часах. |
| **Годовой план добычи** | `135 412 тн` | Открывает экран **выполнения годового и помесячного бизнес-плана**: факт с начала года, процент выполнения, текущее отклонение и прогноз до конца года. |
| **Колокольчик уведомлений** | Кружок `28` | Раскрывает панель **оперативных технологических отклонений и алертов** (срыв подачи, нулевой замер на АГЗУ, превышение давления). Клик по строке открывает карточку с возможностью назначить ответственного инженера и внести комментарий. |

### Б. Левый блок: График суточной добычи и скважины

| Элемент | Действие | Что делает система |
| :--- | :--- | :--- |
| **Радиокнопки «Жидкость / Нефть»** | Клик | Мгновенно переключает график между динамикой добычи жидкости (м³/сут) и чистой обезвоженной нефти (т/сут). |
| **Чекбокс «Показать с накоплением»** | Клик | Переключает режим отображения: почасовой дебит либо интегральная накопительная кривая добычи с начала текущих суток. |
| **Дропдаун «Сортировка»** | Клик | Открывает меню быстрой фильтрации скважин: по снижению/росту дебита, по проценту обводненности, по нулевым замерам, по номеру скважины. |
| **Иконка списка / таблицы** | Клик | Переключает представление фонда между компактными плитками и развернутой табличной ведомостью замеров. |
| **Карточка любой скважины** *(например, UZV_0121, UAZ_0052, UAZ_0066)* | Клик | Открывает **«Паспорт скважины»**: текущие телеметрические данные (дебит нефти/жидкости, обводненность, забойное давление, динамический уровень, частота вращения, дата последнего замера на АГЗУ). |

### В. Центральная и правая мнемосхема: Наземное оборудование

| Узел мнемосхемы | Интерактивность | Что открывается / отображается |
| :--- | :--- | :--- |
| **Кнопки АГЗУ («АГЗУ 1», «1С», «2», «3», «4», «5», «6»)** | Клик по номеру | Переключает всю обвязку замерной установки на выбранный номер, загружая перечень подключенных к нему скважин. |
| **Отводы скважин на АГЗУ (отводы 1–14)** | Клик по номеру или дебиту | Подсвечивает линию направления потока сырья в замерный трап и открывает карточку технологического режима скважины. |
| **Центральный круговой блок АГЗУ** | Клик по кругу *(0.31 МПа, 00:01, 21.31 °C)* | Открывает карточку **текущего замера АГЗУ**: рабочее давление сепаратора, температура смеси, продолжительность цикла замера, перепад на расходомере. |
| **Резервуары РГС №2, №3, №4 (V 90 м³)** | Клик по резервуару | Открывает паспорт горизонтального отстойника: общий уровень взлива (см), граница раздела «нефть–вода», толщина водяной подушки, температура продукта. |
| **Резервуары РВС 1 (1000 м³) и РВС 2 (2000 м³)** | Клик по резервуару | Открывает технологическую панель вертикального товарного резервуара: взлив, масса товарной нефти в наличии, свободный объем. |
| **Печи подогрева №1 и №2** | Клик по блоку печи | Открывает карточку трубчатого нагревателя: температура сырья на входе и выходе, давление топливного газа, режим работы горелок. |
| **Насосная перекачки нефти и насосная ППД** | Клик по насосу (1, 2) | Открывает статус насосного агрегата: давление на приеме и нагнетании, температура подшипников, токовая нагрузка электродвигателя. |
| **Узлы учета (Узел 1, Учет воды, Учет газа)** | Клик по табло | Открывает коммерческие и технологические параметры расходомеров: массовый расход (т/ч), плотность смеси (кг/м³), накопленный объем. |
| **Магистральный коллектор («С.Жолдыбай, 25 км»)** | Клик по блоку | Открывает параметры магистральной перекачки на головной пункт подготовки нефти (ЦППН): давление в линии, гидравлический режим трассы. |
| **Блок БДР (Блок дозирования реагента)** | Клик по блоку | Открывает карточку дозирования деэмульгатора: удельная норма подачи (г/т), текущий остаток реагента в емкости, режим насоса-дозатора. |

### Г. Боковое меню (Иконка гамбургера ☰ в левом верхнем углу)

Боковое меню содержит 9 полнофункциональных разделов:

1. **Мониторинг добычи:**
   * Сворачивает боковую панель и возвращает на главный интерактивный экран мнемосхемы со всплывающим уведомлением.
2. **Обратный расчет:**
   * Открывает окно баланса добычи с 4 специализированными вкладками:
     * *Добыча нефти:* сравнение замеров по АГЗУ и сдачи в коллектор, вычисление коэффициента расхождения.
     * *Добыча жидкости:* сводный баланс по объему жидкости (м³).
     * *Добыча воды:* учет попутно добываемой пластовой воды и коэффициента утилизации.
     * *Баланс:* распределение небаланса между скважинами и технологические потери.
3. **ПРС (Мониторинг текущих ремонтов):**
   * Открывает интерактивное табло активных ремонтов в реальном времени с прогресс-барами готовности по каждой бригаде (какой этап выполняется: глушение, спуско-подъем, опрессовка).
4. **Сводки ПРС:**
   * Открывает сводный аналитический отчет за месяц: общее число ремонтов, распределение по видам подземных работ, средняя длительность ремонта.
5. **ИИ-ассистент (тест):**
   * Интеллектуальный помощник диспетчера:
     * *Анализ аномалий:* автоматический список критических отклонений телеметрии с вероятностью и рекомендацией (утечка, перегрев, срыв подачи насоса).
     * *Консоль оператора:* возможность задать любой вопрос нейросети или выбрать готовые команды («Прогноз выполнения плана», «Риски простоя скважин», «Анализ баланса АГЗУ»).
6. **Эффективность ПРС (тест):**
   * Технико-экономический анализ эффективности ремонтов: удельные затраты на тонну дополнительно добытой нефти, рейтинг подрядных бригад, соблюдение нормативных сроков.
7. **Обходы:**
   * Электронный журнал линейных обходов оборудования операторами добычи: маршрутные чек-листы, статус осмотра узлов, выявленные замечания и фотофиксация.
8. **Отчеты:**
   * Генератор оперативных сводок и технологических рапортов. Выбор диапазона дат и скачивание готовой выгрузки в формате Excel / PDF.
9. **Выход:**
   * Диалог безопасного завершения сеанса работы диспетчера с возможностью подтвердить выход либо остаться в системе.

## 4. Как запустить систему локально

1. **Автономный полноэкранный режим (как на пульте диспетчера):**
   ```
   http://localhost:8088/цд/production-monitoring/index.html
   ```
   *Ширина автоматически рассчитывается под окно вашего браузера, горизонтальная прокрутка плавно перемещает по всем 4 технологическим секциям без пустоты справа.*

2. **В составе общего Ситуационного центра месторождений:**
   ```
   http://localhost:8088/цд/v4.html
   ```
   *Перейдите в раздел «Цифровой двойник добычи и наземной инфраструктуры» (кнопка 3 в левом 3D-меню). Экран откроется во встроенном интерактивном окне.*

## 5. Структура ключевых файлов

* `index.html` — главная страница разметки с виджетами, векторной мнемосхемой (SVG) и структурой оборудования.
* `app.js` — логика интерактивности:
  * алгоритм автоматического зума и подгонки ширины (`updateZoom`),
  * обработка кликов по всем скважинам, резервуарам, печам и кнопкам,
  * генерация модальных окон (обратный расчет, ПРС, ИИ-ассистент, обходы, паспорта скважин),
  * локальный мок-сервер ответов телеметрии и графиков.
* `app.css` — стили темной промышленной темы, компактные таблицы, всплывающие окна и точные размеры области прокрутки.
* `public/style.css` — оригинальные стили технологической мнемосхемы и оборудования.
* `README.md` — настоящее руководство пользователя и описание интерактивных возможностей.
