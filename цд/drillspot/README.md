# DrillSpot · Demo

Автономная вёрстка экрана Demo / East Moldabek / 2793 по предоставленному
скриншоту и авторизованной странице DrillSpot. Работает без сборки,
фреймворков, внешних запросов и подключения к аккаунту.

Открыть `index.html` напрямую или запустить из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Адрес: <http://127.0.0.1:8765/цд/drillspot/>.

## Файлы

- `index.html` — структура экрана и SVG-значки.
- `styles.css` — палитра, размеры, компоновка, состояния элементов.
- `data.js` — списки окон, скважин, показателей и описание дорожек.
- `app.js` — управление интерфейсом и отрисовка графиков на Canvas.
- `logo.svg` — локальная векторная реконструкция знака.
- `fonts/` — Inter и Barlow Semi Condensed из публичных ресурсов оригинала,
  с лицензиями SIL Open Font License; подключаются локально.

## Реализовано

Верхняя лента Numeral, деревья Windows / Object tree / Group tree,
вкладки, контекст скважины, таблица траектории, числовые карточки,
столбчатый график, обзор глубины и цветные дорожки мониторинга.
Работают поиск, сворачивание секций и панелей, фильтр открытых окон,
выбор скважины и показателя, переключение Time / MD, Last points,
скрытие трасс нажатием на заголовок и курсор времени на графиках.
Вкладки поддерживают переключение стрелками, меню закрываются по Escape.

Компоновка рассчитана на настольный экран. Размеры масштабируются вместе
с шириной окна, высота графиков — по доступному месту. При ширине меньше
760 px сохраняется минимальная ширина рабочей панели.

## Границы текущего этапа

3D-модель намеренно отложена: `.model-area` содержит только плоскую
сетку и подписи. В следующем этапе модель можно вставить в этот контейнер,
сохранив таблицу и строку состояния поверх неё.

Числа в карточках и таблице перенесены с исходного экрана. Кривые Canvas —
детерминированная визуальная имитация, а не выгрузка измерений. Выбор других
окон и скважин меняет контекст, но сохраняет демонстрационные показатели.
Калькулятор, редактирование формата скважин и внешние сервисы пока
обозначены элементами интерфейса. Изменения в исходный DrillSpot не отправляются.

Это реконструкция по изображению, а не копия исходного приложения;
пиксельное совпадение всех деталей и кривых не подтверждено.

## Проверка

Проверены синтаксис обоих JS-файлов, уникальность HTML ID, наличие локальных
ресурсов, отображение в браузере и отсутствие ошибок в его консоли.
В браузере проверены фильтрация `2793`, восстановление списка, Time / MD,
сворачивание ленты и боковой панели, выбор Total Gas и возврат Hole Depth.
